# Market signal context acceptance

- Under 1 point: NEUTRAL; informational only.
- 1+ point toward the Dashboard tier side: CONFIRMS TIER.
- 1+ point against the Dashboard tier side: CONFLICTS WITH TIER.
- 1+ point confirmation displays 13–3 ATS, n=16 as an early sample, not a game probability.
- Moneyline movement remains separate and does not classify the ATS confirmation.
- Existing tier/category signal remains visible and primary.
- No Odds API refresh is triggered by this UI enhancement.
